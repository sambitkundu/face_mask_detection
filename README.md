# Face Mask Detection using CNN

This project implements a Convolutional Neural Network (CNN) to classify whether a person is wearing a face mask or not.

## Features
- Image preprocessing (resizing and normalization)
- CNN model built using TensorFlow/Keras
- Face detection and classification
- Predicts "with mask" or "without mask"

## Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib

## Dataset
- Face Mask Dataset (Kaggle)

## How to Run
1. Open the notebook in Google Colab
2. Run all cells
3. Upload an image to test prediction
